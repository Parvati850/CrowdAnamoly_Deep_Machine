# Dataset Directory

This folder contains the dataset manifest and the extra (unlabelled) crowd videos.

## Structure

```
dataset/
├── dataset_manifest.csv        ← generated by scripts/inspect_dataset.py
├── README.md                   ← this file
└── Crowd Dataset - extra/      ← unlabelled videos (DO NOT label automatically)
```

## Labelled video locations (inside the project)

| Folder | Label | Count | Decodable |
|--------|-------|-------|-----------|
| `config/Normal Crowds/` | normal | 12 | 9 |
| `config/Abnormal Crowds/` | abnormal | 8 | 8 |
| `dataset/Crowd Dataset - extra/` | unknown | 23 | 17 |

## Non-decodable files

Nine .mov files fail to decode with OpenCV on Windows because they use a
zlib-compressed QuickTime container format (`error reading header`).
These are excluded from training and evaluation.

**Affected files:**
- `81872953_l.mov` (Normal)
- `sfw20110024_l.mov` (Normal)
- `shibuya1.mov` (Normal)
- `1379-7_l.mov`, `1379-8_l.mov`, `81712424_l.mov`, `82409835_l.mov`,
  `82409905_l.mov`, `965-83_l.mov` (Extra)

## Rules

- **Do not** rename, delete, or move any original video files.
- **Do not** assign labels to the extra folder without human review.
- **Do not** commit large video files to version control.
